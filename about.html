About OmniText

A practical workspace for everyday text

OmniText is a browser-based writing and text productivity toolkit. It brings together text analysis, text formatting, lightweight writing review, and a Markdown workspace in one place.

Our purpose

Help people inspect, organize, transform, and prepare text more efficiently with accessible tools and practical guidance.

What you can do with OmniText

  • Analyze text: review word, character, line, paragraph, and estimated reading-time counts.
  • Format text: apply common case conversions, clean whitespace, remove duplicate lines, sort lines, and use other basic transformations.
  • Review writing: receive simple rule-based observations, such as long-sentence and repeated-word signals. These observations are prompts for editing, not a full grammar or fact-checking service.
  • Work with Markdown: write Markdown, preview formatted output, copy the source, and download a Markdown file.
  • Learn: read practical guides about text metrics, formatting, and Markdown.

How the tools work

Text entered into the core text utilities and writing review is processed by scripts running in your browser. The Markdown preview uses third-party JavaScript libraries loaded by the page. Like most websites, loading OmniText may also involve requests to hosting, font, content-delivery, analytics, or advertising providers where enabled. See our Privacy Policy for details.

Our approach

We aim to make the tools understandable and useful. Automated counts and writing observations can have limitations, especially with different languages, symbols, formatting, and writing styles. Please review important output before using it in professional, academic, or other consequential settings.
